# Touch-control artwork

`steering-wheel.svg` and `brake-pedal.svg` are extracted from **Car Controls**
by **looneybits**, published on 5 September 2015 under **CC0 1.0 Universal**.

- Author's release: <https://opengameart.org/content/car-controls>
- Original SVG: <https://opengameart.org/sites/default/files/car_controls.svg>
- License: <https://creativecommons.org/publicdomain/zero/1.0/>
- Local license text: [CC0-1.0.txt](CC0-1.0.txt)
- Unmodified artwork source: [sources/car-controls.svg](sources/car-controls.svg)
- Source and derivative hashes: [sources/manifest.json](sources/manifest.json)

Adaptations: extracted wheel group `g9211` and brake-pedal group `g37281`;
removed the blue sheet background, unrelated objects, editor metadata and
unused gradient definitions; fitted separate transparent SVG view boxes.
The original vector paths, colours and gradients of each control are retained.
No SuperTuxKart artwork is included in these SVGs.

CC0 does not require attribution; this notice records the source and makes the
editable artwork and its provenance easy to find. It applies only to these
control assets, not to the original RedCat game assets or the whole project.

## Generated bonus button

`bonus.png` was created for this port with the built-in `image_gen` tool on
23 October 2026, at the user's request. It uses the original menu's warm
orange/red palette and cat-paw motif as style guidance. It is a new asset,
not recovered original game artwork and not part of looneybits' CC0 set.
The initial generation prompt is saved in [bonus-prompt.txt](bonus-prompt.txt).
The icon was then corrected against the original round `mn_0210a/b/c` and
`mn_0211a/b/c` buttons: three red toe pads above the circular main face,
brighter native red/yellow colours, and the retained lightning bolt. The
source and dist reference images are byte-identical. Only the new icon was
edited; its small responsive display dimensions are unchanged.
The exact edit prompt is saved in [bonus-edit-prompt.txt](bonus-edit-prompt.txt).
