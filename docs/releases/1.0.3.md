# RedCat SuperKarts v1.0.3 — desktop and source release

Version 1.0.3 makes the race far lighter, above all on phones, and loads it much
faster. It adds two optional improvements over the original: kart shadows on the
road surface and engine lights that follow the kart smoothly. Gameplay
is unchanged. Existing saves, profiles, unlocks, settings and records keep working;
no reset or manual migration is required. The version appears in
**Instellingen → Meer instellingen**.

Download from [GitHub](https://github.com/NostalgiaRealm/RedCat-SuperKarts/releases/tag/v1.0.3)
or [GitLab](https://gitlab.com/Nostalgia_Realm/RedCat-SuperKarts/-/releases/v1.0.3).
See the [1.0.3 changelog](../../CHANGELOG.md#103--2026-10-30) and
[mobile performance](../mobile-performance.md) for the measurements.

## Changes since 1.0.2

### Performance

Measured on emulated phones, Netherlands track:

| | Before | After |
| --- | --- | --- |
| Main-thread budget, portrait at 4× throttle | 119% | 24% |
| Main-thread budget, budget phone at 6× throttle | 162% | 44% |
| Memory allocated per game update | 3660 KiB | about 430 KiB |
| Draw calls per frame | about 320 | about 140 |
| Requests to load a race | 1514 | 221 |
| Transferred to load a race | 59 MB | 26 MB |

The website download of a race is 15.4 MB, because the server also compresses it.
These are emulated phones with a software GPU: compare the numbers between builds;
they do not predict a real phone's frame rate.

### Visible changes

- **Phones and tablets:** **Automatisch** now stops at about 1 megapixel, which
  looks slightly softer. The new **Volle schermresolutie** uses every screen pixel.
- **Schaduwen op het wegdek**, on by default: kart shadows lie on the road surface
  instead of disappearing below it in places. Off shows the original shadow.
- **Motorlicht volgt de kart**, on by default: the light behind each kart's engine
  moves smoothly with the kart instead of sinking into the engine at speed. Off
  keeps the earlier behaviour; the original never showed this flicker.

### Website

- The game runs from a URL folder, such as
  [games.nostalgiarealm.com/redcatsuperkarts](https://games.nostalgiarealm.com/redcatsuperkarts/).
- `tools/deploy-website.sh` builds and uploads the site in one command.

## Run the source locally

Extract `RedCat-SuperKarts-1.0.3-source.tar.gz`, or clone the repository at the
`v1.0.3` tag. Install Node.js 24 and npm, then open a terminal in the project:

```sh
npm ci
npm start
```

Open [the local game](http://127.0.0.1:4173/). Keep the terminal open while
playing; Ctrl+C stops the server. Prepared assets are included, and the start
command refreshes the runtime bundles from `source/`. After installing
dependencies, `npm run desktop` opens the same game in Electron.

## Original-code reference

The entire `original-source/` folder is published on both hosts and included
in the source archive, with a separate archive for convenient inspection. It
contains recovered C-like pseudocode, assembly, indexes, copied runtime
inputs, provenance and analysis files, with nothing intentionally omitted.
These files are **not the original developers' authored source project**; see
its [guide](../../original-source/README.md) and the
[publication policy](README.md).

## Release scope

- **Before packaging:** the full Node test suite passed on the release source,
  including original-instruction fixtures and a new bit-exact race trace on all
  six tracks. On the Netherlands track, 42 framebuffer hashes match the
  pre-optimization build. Browser tests passed in headless Chromium 145 with software
  rendering: HUD framebuffer, MSAA, touch controls, engine lights, more settings,
  streams and the version check. WebKit 26 with iPhone emulation ran one race
  without errors.
- **Limited on request:** browser verification of the performance work used one
  track. Framebuffer hashes for the other five tracks and for MSAA, render scale
  and low-effects settings were not rerun, and most other browser tests, including
  Firefox, were not rerun on this build.
- **Packaging:** the normal build checks run for every package. Linux and Windows
  packages are built on Fedora Linux (Windows cross-built); macOS packages are
  built by the GitHub-hosted macOS workflow.
- **Not run:** launch tests of the finished packages, full races, physical phones
  or tablets, real Safari and comparisons against a working original Windows
  installation.

Earlier validation records keep their original scope. See
[remaining work](../remaining-work.md) and [validation records](../validation.md).

Original game, media and font rights remain with their respective owners.
This release does not grant a new license for those assets.
