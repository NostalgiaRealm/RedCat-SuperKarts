# RedCat SuperKarts 2.0.0 — the original race, recompiled

Version 2.0.0 is a new port. Until now RedCat SuperKarts was a reconstruction written by hand in JavaScript and
Three.js. This version runs the game's own original race program, `rcskspel.dat` from 2000, recompiled from x86
machine code to WebAssembly, with a JavaScript layer that gives it a screen, sound, files and input. What the race
does is therefore what the original does: physics, AI, rules, timing, HUD, camera, sound and the race's own pause,
quit, finish and game-over screens are the original code. The differences that remain on purpose are listed in
[docs/intentional-differences.md](../intentional-differences.md).

The menus, Adventure, QuickRace, highscores and settings are the JavaScript reconstruction's, and so are its
additions around the race. Existing saves are taken over.

Download from [GitHub](https://github.com/NostalgiaRealm/RedCat-SuperKarts/releases/tag/v2.0.0) or
[GitLab](https://gitlab.com/Nostalgia_Realm/RedCat-SuperKarts/-/releases/v2.0.0), or play at
[games.nostalgiarealm.com/redcatsuperkarts](https://games.nostalgiarealm.com/redcatsuperkarts/). See the
[changelog](../../CHANGELOG.md).

The JavaScript port stays available: its releases up to 1.0.3 are unchanged, its source is on the branch
`javascript-port`, and on the website it is at
[`classic/`](https://games.nostalgiarealm.com/redcatsuperkarts/classic/).

## Your saves

- **Website:** the new version is at the same address and reads the same saves: profiles, highscores, records,
  unlocked countries, settings. The old version at `classic/` shares them.
- **Desktop app:** 2.0.0 has the same identity and save folder as 1.0.x, so installing it keeps everything.
  Checked with saves written by the 1.0.3 Linux app.
- **Another site or browser:** Instellingen → Meer instellingen → Opslag exporteren / Opslag importeren moves the
  saves as a file. For the old version's website, which has no export button, the README's
  [Saves](../../README.md#saves) section has a one-line console command that writes the same file.

## What it keeps from the JavaScript reconstruction

- Any screen shape: wider shows more at the sides, taller more above and below, with the HUD laid out as in 1.0.3
  and clear of notches and touch controls on phones.
- Resolution, render scale and MSAA; pictures smoothed to the display's rate between the game's 25 ms steps; at
  most 60 frames a second on phones.
- Keyboard, controller and touch controls; the controller and the touch wheel steer through the game's own analog
  joystick code.
- Schaduwen op het wegdek, Motorlicht volgt de kart, Vrij vliegen, recovery of a stuck kart, a silent pause when
  the window loses focus, FPS weergeven.

## What changes for players

- The race behaves as the original does, also where the reconstruction differed from it.
- Key bindings on letter keys work as set. The original's own debug and cheat keys are off; `?cheats` in the
  address turns them on.
- The website needs a browser that can isolate the page and share memory with its workers (current Chrome, Edge,
  Firefox). Other browsers get a notice with a link to the old version.
- A first race on the website downloads about 30 MB (1.0.3: about 15 MB), a second race on another track about
  8 MB; a second visit about 1 MB.

The desktop packages contain Electron, the recompiled race and the game's files; nothing else is needed. Windows
packages have no publisher signature; macOS packages are ad-hoc signed and not notarized, as before. The
`integrity-*.json` files record what each package contains; `SHA256SUMS.txt` has the checksums. Building from
source is described in [docs/building.md](../building.md) and hosting in [docs/hosting.md](../hosting.md).

## Tested and not tested

- **Tested:** the project's checks pass in headless Chromium with a software GPU: the menu to a finished race and
  back, Adventure and QuickRace results, pause, quit, keyboard, controller and touch (simulated), every screen
  shape, the race's additions, loading, the save take-over. The website package was checked behind a stand-in
  server with the server's headers, also in Firefox 146. The Linux x64 desktop build starts, races and reads
  1.0.3's saves.
- **Not tested:** real phones and tablets, Safari, a physical GPU, the Windows and macOS packages on their own
  systems, the AppImage through FUSE, sound by ear against the original, a full Adventure played to its end.
