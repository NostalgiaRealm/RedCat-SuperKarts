# RedCat SuperKarts v1.0.1 — desktop and source release

Version 1.0.1 brings the port closer to the original game. A comparison
against the recovered original code found ten unintended differences in
racing, saves, audio settings and the intro; this release corrects them.
Intentional browser and desktop features are unchanged. Existing saves,
profiles, unlocks, settings and records keep working; no reset or manual
migration is required. The version appears in
**Instellingen → Meer instellingen**.

Download from [GitHub](https://github.com/NostalgiaRealm/RedCat-SuperKarts/releases/tag/v1.0.1)
or [GitLab](https://gitlab.com/Nostalgia_Realm/RedCat-SuperKarts/-/releases/v1.0.1).
See the [1.0.1 changelog](../../CHANGELOG.md#101--2026-10-28) and the
[comparison report](../original-comparison-2026-10-28.md) for the evidence.

## Changes since 1.0.0

### Racing

- **Bonus pickups:** the player no longer waits 250 ms between pickups, so
  closely spaced or overlapping pickups can be collected one after another.
  As in the original, only opponents have that cooldown.
- **Starting rank:** a race now starts with the player ranked where they
  finished the previous completed race, as the original reads it from
  Race.ini. Time trials and duels still start at rank 0. This affects the
  rank portraits, overtake voices and opponents' rank-based decisions at the
  start, not the grid positions.
- **Lap time after the finish:** the lap time stays frozen during the results,
  as in the original, including when the window loses focus.
- **Waypoint order:** the player's waypoint is chosen before the ground
  update, as it already was for opponents.
- **Keyboard input:** throttle, brake and steering now round like the
  original's single-precision arithmetic. The differences are tiny.
- **Random numbers:** the race's random number stream includes the original's
  draw when the player's record is first used. Normal play looks the same.
- **Results and AI details:** saved opponent result times use their current
  progress, and the unused AI forced-route counter reads the correct profile
  field.

### Settings and menus

- **Volumes:** music and effects volumes of 29, 57 and 58% no longer lose 1%,
  and the effects volume no longer drops further after each race. Values
  that had already drifted stay as saved.
- **Intro skipping:** as in the original, only keys that type a character
  skip the intro. Arrow keys and Alt combinations no longer skip it, and
  Backspace now does. Controller, mouse and touch skipping are unchanged.

### Documentation

- A new [comparison report](../original-comparison-2026-10-28.md) records the
  evidence for each correction, the intentional differences kept and the
  open questions.
- Focused tests cover each correction. The 1.0.0 publication notes and the
  source archive command were clarified.

## Run the source locally

Extract `RedCat-SuperKarts-1.0.1-source.tar.gz`, or clone the repository at the
`v1.0.1` tag. Install Node.js 24 and npm, then open a terminal in the project:

```sh
npm ci
npm start
```

Open [the local game](http://127.0.0.1:4173/). Keep the terminal open while
playing; Ctrl+C stops the server. Prepared assets are included, and the start
command refreshes the runtime bundles from `source/`. After installing
dependencies, `npm run desktop` opens the same game in Electron.

## Original-code reference

The entire `original-source/` folder is published on both hosts and included
in the source archive, with a separate archive for convenient inspection. It
contains recovered C-like pseudocode, assembly, indexes, copied runtime
inputs, provenance and analysis files, with nothing intentionally omitted.
These files are **not the original developers' authored source project**; see
its [guide](../../original-source/README.md) and the
[publication policy](README.md).

## Release scope

- **Before packaging:** focused unit tests for every correction, every
  full-simulation test and 14 browser tests passed on the release source. The
  browser tests ran in headless Chromium 145 with software rendering. See the
  [comparison report](../original-comparison-2026-10-28.md) for the exact
  runs, including one fixed-seed test whose seed was changed.
- **Packaging:** the normal build checks run for every package: the staged
  game files are verified byte for byte, and each packaged application is
  checked against them. Linux and Windows packages are built on Fedora Linux
  (Windows cross-built); macOS packages are built by the GitHub-hosted macOS
  workflow.
- **Not run:** the full test suite, launch tests of the finished packages,
  full races, physical devices and comparisons against a working original
  Windows installation.

Earlier validation records keep their original scope. See
[remaining work](../remaining-work.md) and
[validation records](../validation.md).

Original game, media and font rights remain with their respective owners.
This release does not grant a new license for those assets.
