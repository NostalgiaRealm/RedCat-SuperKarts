# RedCat SuperKarts v0.9.0 — desktop and source release

This source update includes the corrected movie proportions, RGB565 race HUD,
redesigned touch controls, original Help navigation and Adventure pre-race
speech. It also includes the menu-flow fixes and original power-up audio audit.
The version appears in **Instellingen → Meer instellingen**.

See the [0.9.0 changelog](../../CHANGELOG.md#090--2026-10-25) for the changes
since 0.1.0, validation scope and remaining limits.

## Desktop downloads

Download from [GitHub](https://github.com/NostalgiaRealm/RedCat-SuperKarts/releases/tag/v0.9.0)
or [GitLab](https://gitlab.com/Nostalgia_Realm/RedCat-SuperKarts/-/releases/v0.9.0):

| Platform | Packages |
| --- | --- |
| Linux x64 | AppImage and `.tar.gz` |
| Windows x64 | NSIS installer and `.zip` |
| macOS Intel | `.dmg` and `.zip` |
| macOS Apple Silicon | `.dmg` and `.zip` |

The packages include the game runtime and assets; Node.js is not required.
The changelog, build metadata and SHA-256 checksums accompany the downloads.
Windows packages have no publisher signature. Mac packages are ad-hoc signed
and are not notarized. See [desktop instructions](../desktop.md).

## Run locally

Install Node.js 24 and npm, then download/extract or clone this source and open
a terminal in its folder:

```sh
npm ci
npm start
```

Open [the local game](http://127.0.0.1:4173/). Keep the terminal open while
playing; Ctrl+C stops the server. Prepared assets are included, so no disc
import or build step is required. After installing dependencies,
`npm run desktop` opens the same source in an Electron window.

## Scope

The eight desktop packages use the existing `v0.9.0` source tag at commit
`7914febbb4dca21531f2eff70833cc1dc0804c60`. The tag is unchanged by the later
packaging workflow and documentation updates. All four platform payload checks
confirm the same 6,868 game files. The Linux package passes a focused launch
and version-menu check with the normal sandbox enabled. Both Mac package
architectures are built and ad-hoc signed on macOS.

Windows and macOS gameplay remain runtime-unverified. No full suite or race
matrix was repeated; earlier focused results retain their documented source
and platform scope. The initial source-only publication is now supplemented
by these desktop downloads.

Full original-game visual, audio and handling parity has not been established.
See [feature status](../feature-parity.md), [validation](../validation.md) and
[remaining work](../remaining-work.md).

Original game, media and font rights remain with their respective owners.
This release does not grant a new license for those assets.
