# RedCat SuperKarts v1.0.0 — desktop and source release

Version 1.0.0 collects the current browser and desktop port, original-code
comparison fixes, automatic movie playback, runtime optimizations and the
separation of editable modules from generated game bundles. Existing saves
keep their formats and locations; no reset or manual migration is required.
The version appears in **Instellingen → Meer instellingen**.

Download from [GitHub](https://github.com/NostalgiaRealm/RedCat-SuperKarts/releases/tag/v1.0.0)
or [GitLab](https://gitlab.com/Nostalgia_Realm/RedCat-SuperKarts/-/releases/v1.0.0).
See the [1.0.0 changelog](../../CHANGELOG.md#100--2026-10-26) for the full list.

## Changes since 0.9.0

- Movies start immediately, with a muted fallback if the browser blocks sound.
  **Geluid inschakelen** enables audio without restarting playback and enters
  fullscreen. The overlapping intro message and Start button are removed.
- Menu entry focus, Return-key release for name entry, bonus/turbo update order,
  engine-sound timing, pause/quit sound continuity and music restart polling
  follow the recovered original routines more closely. Intentional browser,
  input, display and stuck-recovery features remain.
- Editable JavaScript, HTML and CSS are in `source/`, with a clear purpose guide.
  Normal browser and Electron launches refresh and execute the smaller set of
  generated files in `src/`. Race and track code load when needed.
- HUD preparation and transform/effect/item work reuse data more efficiently.
  Browser and desktop file serving share one implementation. Canceled track
  loads no longer reopen after Back, and unavailable storage falls back safely.
- Documentation is reorganized, current instructions use the new folder layout,
  and retained historical evidence stays separate from present release claims.
- The complete `original-source/` folder is published on both hosts and included
  in source archives, with a separate archive for convenient inspection.

## Run the source locally

Extract `RedCat-SuperKarts-1.0.0-source.tar.gz`, or clone the repository at the
`v1.0.0` tag. Install Node.js 24 and npm, then open a terminal in the project:

```sh
npm ci
npm start
```

Open [the local game](http://127.0.0.1:4173/). Keep the terminal open while
playing; Ctrl+C stops the server. Prepared assets are included. The start
command refreshes the runtime bundles, so no separate build command or original
disc import is required. After installing dependencies, `npm run desktop`
opens the same game in Electron.

## Original-code reference

The entire `original-source/` folder is retained, including recovered C-like
pseudocode, matching assembly, indexes, copied runtime inputs, provenance,
export tools and the folder's working/helper files. No subfolders or ignored
files within that reference are intentionally omitted from its publication.
Every future release update must continue including this complete folder on
GitHub and GitLab and in the release source archives.

These files were recovered from the five shipped runtime modules. They are
**not the original developers' authored source project** and are not presented
as a compilable original game. Decompiler warnings, uncertain boundaries and
coverage limits remain documented in its [guide](../../original-source/README.md).
The JavaScript port is edited in [`source/`](../../source/README.md); the
recovered reference is not loaded by the running game. See the
[comparison report](../full-source-audit.md) and
[standing publication policy](README.md).

## Release scope

**No tests or build checks are run for this release, as explicitly requested.**
Desktop packages are built and published without launch checks, gameplay tests,
payload verification or archive-content checks. The build-time verifier is
skipped using `RCSK_SKIP_BUILD_CHECKS=1`; the macOS workflow also skips its
metadata and integrity-report checks for this release.

Prior focused source, storage-compatibility and original-instruction results
remain historical evidence for their recorded checkpoints. They are not new
1.0.0 package validation. Full original Windows race parity, a fresh full-race
matrix, historical GPU precision and physical target-device gameplay remain
open. See [remaining work](../remaining-work.md) and
[validation records](../validation.md).

Original game, media and font rights remain with their respective owners.
This release does not grant a new license for those assets.
