# RedCat SuperKarts v1.0.2 — desktop and source release

Version 1.0.2 continues the comparison with the recovered original code. It
corrects Adventure, rescue, track, HUD and menu details. The game now
calculates with the same double precision as the original, instead of single
precision. Intentional browser and desktop features are unchanged. Existing
saves, profiles, unlocks, settings and records keep working; no reset or
manual migration is required. The version appears in
**Instellingen → Meer instellingen**.

Download from [GitHub](https://github.com/NostalgiaRealm/RedCat-SuperKarts/releases/tag/v1.0.2)
or [GitLab](https://gitlab.com/Nostalgia_Realm/RedCat-SuperKarts/-/releases/v1.0.2).
See the [1.0.2 changelog](../../CHANGELOG.md#102--2026-10-29) and the
[comparison report](../original-comparison-2026-10-28.md) for the evidence.

## Changes since 1.0.1

### Racing

- **Precision:** driving, collisions, opponents and effects now calculate
  with the original game's double precision. The original sets it at start-up
  and keeps it with every DirectX runtime checked, from 5.0 to 9. Each
  difference is tiny, but races now follow the original's arithmetic step by
  step.
- **Rescues:** when several karts are rescued at once, they are handled newest
  first and retire as in the original. A homing rocket's arm shrinks with a
  rescued kart. During the player's own rescue, the wheels and slope forces
  use the shrinking kart, as in the original.
- **Track surface:** ground heights, slopes and the fallback planes use the
  original's plane calculation. Scenery and pickup rotations use its degree
  conversion, which changes some angles by the smallest possible step.
- **Bubble hits:** a floating kart follows the route plane, and the player's
  slide resets when the original does.

### Adventure and menus

- **Result screen:** Escape, controller B or Start now counts the race, as the
  original's Back does, instead of discarding it.
- **New profiles:** Back is disabled in new-profile character selection, as in
  the original.
- **Profile choice:** the Adventure screen keeps the profile you accepted,
  not the last one you browsed.
- **Volume sliders:**
  - Arrow keys move 1, Page Up and Page Down move 17, Home is 100 and End is 0.
  - Clicking the track moves 17 towards the pointer and repeats while held.
  - Dragging follows the pointer, and the thumb sits at the original height.

  Touch and controller input are unchanged.
- **HUD:** text, mesh positions and string scales follow the original's
  arithmetic.

### Development and documentation

- The local development server no longer stops when a browser cancels a file
  request.
- The [comparison report](../original-comparison-2026-10-28.md) now covers
  the second comparison pass, the precision switch with its runtime and
  DirectX evidence, and the follow-up fixes.
- New original-instruction fixtures cover both precisions, including the
  rescue queue, track planes, placement angles, HUD layout and kart sweeps
  with rails. The tests compare them exactly.
- Browser tests no longer resume only the clock or start their own ticks
  behind the race clock.

## Run the source locally

Extract `RedCat-SuperKarts-1.0.2-source.tar.gz`, or clone the repository at the
`v1.0.2` tag. Install Node.js 24 and npm, then open a terminal in the project:

```sh
npm ci
npm start
```

Open [the local game](http://127.0.0.1:4173/). Keep the terminal open while
playing; Ctrl+C stops the server. Prepared assets are included, and the start
command refreshes the runtime bundles from `source/`. After installing
dependencies, `npm run desktop` opens the same game in Electron.

## Original-code reference

The entire `original-source/` folder is published on both hosts and included
in the source archive, with a separate archive for convenient inspection. It
contains recovered C-like pseudocode, assembly, indexes, copied runtime
inputs, provenance and analysis files, with nothing intentionally omitted.
These files are **not the original developers' authored source project**; see
its [guide](../../original-source/README.md) and the
[publication policy](README.md).

## Release scope

- **Before packaging:** the full Node test suite passed on the release source
  (751 of 751 tests). Browser tests passed in headless Chromium 145 with
  software rendering: driving, QuickRace, bundle, variable cadence, player
  recovery, both rescue tests, menu entry and settings, audio and more
  settings, menu flow, Adventure, the three HUD tests, the intro and the
  version check. The menu settings test also passed in Firefox 146. See the
  [comparison report](../original-comparison-2026-10-28.md) for the exact
  runs, including one fixed-seed test whose seed was changed.
- **Packaging:** the normal build checks run for every package: the staged
  game files are verified byte for byte, and each packaged application is
  checked against them. Linux and Windows packages are built on Fedora Linux
  (Windows cross-built); macOS packages are built by the GitHub-hosted macOS
  workflow.
- **Not run:** launch tests of the finished packages, full races, physical
  devices and comparisons against a working original Windows installation.

Earlier validation records keep their original scope. See
[remaining work](../remaining-work.md) and
[validation records](../validation.md).

Original game, media and font rights remain with their respective owners.
This release does not grant a new license for those assets.
