# RedCat SuperKarts v0.1.0 — source release

The current browser and Electron source, together with all prepared game
assets needed to run it locally. No installers, AppImages or other desktop
builds are included.

## Run locally

Install Node.js 24, including npm. Download and extract the source archive,
or clone the repository, then open a terminal in the project folder:

```sh
npm ci
npm start
```

Open **http://127.0.0.1:4173/**. Keep the terminal open while playing;
Ctrl+C stops the server. The original disc does not need to be imported for
this release because the prepared assets are included.

For a desktop window using the same source, run `npm run desktop` after
`npm ci`. Electron downloads its pinned runtime if needed. This does not
create a desktop package.

## Included

- Original menus, six circuits, four playable characters, four active race
  modes and three difficulty levels.
- QuickRace and Adventure progression, profiles, records and reward movies.
- Original artwork, models, textures, music, sound, movies, fonts and help
  content in their prepared runtime formats.
- Keyboard, touch and controller input, widescreen support, optional MSAA,
  free flight and track unlocking.
- Recent HUD, lap-time, quit-screen, recovery and timing corrections; uncapped
  rendering; original 16-bit texture conversion and RGB565 scene rendering.
- Source, asset-preparation tools, focused tests, retained fixtures and
  research/validation documentation.

See `README.md` for controls, settings and setup, `docs/desktop.md` for future
desktop packaging, and `docs/hosting.md` for static hosting.

## Validation and scope

The latest rendering change passed 16 focused unit tests and seven relevant
browser test runs, including 197 pixel comparisons. Publication checks cover
the included files and local launch; no full test suite, full race matrix or
new game build is part of this release preparation. Earlier validation results
retain their documented source and platform scope.

Full original-game visual, audio and handling parity has not been established.
Historical GPU behaviour and platform/device validation limits are documented
in `docs/feature-parity.md` and `docs/validation.md`.

Original game, media and font rights remain with their respective owners.
This release does not grant a new license for those assets.
