# RedCat SuperKarts 2.0.3

A small release for [2.0.0](2.0.0.md), the recompiled port. Saves and settings are unchanged.

Download from [GitHub](https://github.com/NostalgiaRealm/RedCat-SuperKarts/releases/tag/v2.0.3) or
[GitLab](https://gitlab.com/Nostalgia_Realm/RedCat-SuperKarts/-/releases/v2.0.3), or play at
[games.nostalgiarealm.com/redcatsuperkarts](https://games.nostalgiarealm.com/redcatsuperkarts/). See the
[changelog](../../CHANGELOG.md).

## Changed

- **A clearer look back.** Holding 3 now shows the track and the karts behind you, framed like A2 Racer 4's look back
  (its chase camera turned round, in the same proportions on SuperKarts' chase camera: 140 units in front of the kart,
  33 up, aimed 25 above the kart). The original's look back stood 40 units in front and aimed 50 above the kart, so it
  showed mostly the kart's front and the sky. This is an intentional difference from the original; the original code
  still selects the camera and the port then sets its place and aim
  ([intentional differences](../intentional-differences.md)).
- **The README lists every intentional difference from the original**, with the details in
  [docs/intentional-differences.md](../intentional-differences.md).

## Downloads

The same packages as 2.0.0: Linux x64 (AppImage, `.tar.gz`), Windows x64 (installer, `.zip`), macOS Intel and Apple
Silicon (`.dmg`, `.zip`), the source and the original-code reference, with `SHA256SUMS.txt` and the `integrity-*.json`
reports. Windows packages are unsigned; macOS packages are ad-hoc signed and not notarized.

## Tested and not tested

- **Tested:** screenshots of the look back against the original's at the same moments of a race; the unit tests, a
  headless race, free flight, the safeguards and key filter, input and keys checks in headless Chromium; the website
  package and the Linux desktop build's launch check.
- **Not tested:** the new look back compared with A2 Racer 4 in play; everything 2.0.0 lists as not tested.
